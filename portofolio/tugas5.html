Technology

Saya menggunakan dan mempelajari berbagai teknologi dalam proses pembuatan website dan aplikasi. Beberapa teknologi yang saya gunakan antara lain HTML untuk membuat struktur website, CSS untuk mengatur tampilan dan desain, JavaScript untuk membuat website lebih interaktif, serta Bootstrap untuk membuat tampilan yang modern dan responsif. Selain itu, saya menggunakan Git dan GitHub untuk mengelola project, menyimpan kode, dan mempelajari version control.
